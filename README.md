# 🧪 Testes automatizados de cadastro com Cypress

Projeto de estudo com testes E2E (ponta a ponta) no site [Automation Pratice](https://automationpratice.com.br).

## ✅ Cenários testados
- Campo nome vazio
- Campo e-mail vazio
- E-mail inválido
- Senha inválida
- Cadastro realizado com sucesso

## 🛠️ Tecnologias
- JavaScript
- Cypress

## ▶️ Como rodar
1. Instale as dependências: `npm install`
2. Abra o Cypress: `npx cypress open`

## ⚠️ Aviso
Todos os dados usados nos testes (nomes, e-mails e senhas) são **fictícios** e foram criados apenas para fins de estudo.
